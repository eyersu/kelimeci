# Kelimeci

A Turkish swipe-to-connect word game for friends and family. Find words on a 4×4 board by swiping through touching letters, alone or in shared online rounds.

Play: https://eyersu.github.io/kelimeci/

Word list based on the headwords of TDK's Güncel Türkçe Sözlük; additional word data from Wiktionary (CC BY-SA 4.0).
